# 나만의 프롬프트 관리 프로그램

Python으로 만든 콘솔 기반 프롬프트 관리 프로그램입니다.

텍스트 생성, 이미지 생성, 영상 생성 등 다양한 용도의 프롬프트를 등록하고 관리할 수 있습니다.  
카테고리별 조회, 키워드 검색, 상세 보기, 즐겨찾기 기능을 제공하며, 긴 프롬프트를 여러 줄로 입력할 수도 있습니다.

등록한 프롬프트와 즐겨찾기 상태는 `prompts.json` 파일에 저장되므로 프로그램을 종료한 후 다시 실행해도 그대로 유지됩니다.

---

## 개발 환경

- Python 3.10 이상
- Visual Studio Code
- Git
- GitHub
- JSON

---

## 실행 방법

1. 프로젝트 폴더를 Visual Studio Code에서 엽니다.
2. 터미널을 실행합니다.
3. 다음 명령어를 입력합니다.

```bash
python prompt_manager.py
```

4. 프로그램이 실행되면 원하는 메뉴 번호를 입력합니다.

실행 화면 예시:

```text
=== 프롬프트 관리 ===
1. 프롬프트 목록 보기
2. 프롬프트 추가
3. 카테고리별 조회
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 관리
7. 즐겨찾기 목록
0. 종료
선택:
```

---

## 주요 기능

### 1. 프롬프트 목록 보기

현재 등록되어 있는 모든 프롬프트의 번호, 카테고리, 제목을 확인할 수 있습니다.

즐겨찾기로 등록된 프롬프트에는 별표가 표시됩니다.

예시:

```text
=== 프롬프트 목록 ===
1. [텍스트 생성] 블로그 작성
2. [이미지 생성] 제품 이미지 생성
3. [영상 생성] 광고 영상 만들기
4. [텍스트 생성] 집배원 아침 안전 응원 메시지 작성 ⭐
```

---

### 2. 프롬프트 추가

새로운 프롬프트의 제목, 내용, 카테고리를 입력하여 등록할 수 있습니다.

긴 프롬프트를 등록할 수 있도록 여러 줄 입력 기능을 지원합니다.

내용을 모두 입력한 후 마지막 줄에 다음과 같이 입력합니다.

```text
END
```

그러면 내용 입력이 종료되고 카테고리 선택 단계로 이동합니다.

---

### 3. 카테고리별 조회

등록된 프롬프트를 카테고리별로 조회할 수 있습니다.

기본 카테고리는 다음과 같습니다.

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

필요한 경우 새로운 카테고리를 직접 입력할 수도 있습니다.

---

### 4. 프롬프트 검색

제목 또는 내용에 포함된 키워드를 이용하여 원하는 프롬프트를 검색할 수 있습니다.

예를 들어 `업무`를 검색하면 제목이나 내용에 `업무`가 포함된 프롬프트를 찾아 보여줍니다.

---

### 5. 프롬프트 상세 보기

프롬프트 번호를 입력하면 해당 프롬프트의 상세 정보를 확인할 수 있습니다.

확인할 수 있는 정보는 다음과 같습니다.

- 제목
- 카테고리
- 즐겨찾기 여부
- 프롬프트 전체 내용

---

### 6. 즐겨찾기 관리

자주 사용하는 프롬프트를 즐겨찾기에 추가하거나 해제할 수 있습니다.

즐겨찾기로 등록된 프롬프트는 목록에서 ⭐ 표시로 쉽게 구분할 수 있습니다.

---

### 7. 즐겨찾기 목록

즐겨찾기로 등록한 프롬프트만 따로 조회할 수 있습니다.

자주 사용하는 프롬프트가 많아졌을 때 필요한 프롬프트를 빠르게 찾는 데 활용할 수 있습니다.

---

## JSON 영구 저장 기능

초기 버전에서는 프로그램 실행 중에만 프롬프트가 유지되고 프로그램을 종료하면 새로 추가한 데이터가 사라졌습니다.

이를 개선하기 위해 JSON 파일 저장 기능을 추가했습니다.

등록한 프롬프트 데이터는 다음 파일에 저장됩니다.

```text
prompts.json
```

프로그램을 다시 실행하면 `prompts.json` 파일을 읽어 기존 데이터를 자동으로 불러옵니다.

따라서 다음 정보가 프로그램을 종료한 후에도 유지됩니다.

- 새로 등록한 프롬프트
- 프롬프트 내용
- 카테고리
- 즐겨찾기 상태

---

## 프롬프트 데이터 구조

각 프롬프트는 Python 딕셔너리 형태로 관리합니다.

예시:

```python
{
    "title": "블로그 작성",
    "content": "SEO에 맞는 블로그 글을 작성해주세요.",
    "category": "텍스트 생성",
    "favorite": False
}
```

각 프롬프트에는 다음 4가지 정보가 저장됩니다.

| 항목 | 설명 |
| --- | --- |
| title | 프롬프트 제목 |
| content | 프롬프트 내용 |
| category | 프롬프트 카테고리 |
| favorite | 즐겨찾기 여부 |

여러 개의 프롬프트는 리스트 형태로 관리합니다.

## 기본 등록 프롬프트

프로그램 최초 실행 시 다음과 같은 기본 프롬프트를 사용할 수 있습니다.

1. 블로그 작성
2. 제품 이미지 생성
3. 광고 영상 만들기

이후 사용자가 필요한 프롬프트를 직접 추가하여 자신만의 프롬프트 저장소로 활용할 수 있습니다.

## 실제 활용 예시

이 프로그램에는 단순한 한 줄 프롬프트뿐 아니라 실제 업무에 사용하는 긴 프롬프트도 저장할 수 있습니다.

예를 들어 다음과 같은 프롬프트를 등록하여 사용할 수 있습니다.

### 집배원 아침 안전 응원 메시지 작성

집배실 단체채팅방에 보낼 안전·응원 메시지를 작성하기 위한 프롬프트를 등록할 수 있습니다.

프롬프트 안에 역할, 작성 기준, 문체, 이모지 사용 방법, 예시 등을 여러 줄로 상세하게 작성해 저장할 수 있습니다.

이렇게 등록한 프롬프트는 필요할 때 검색하거나 즐겨찾기 목록에서 찾아 다시 활용할 수 있습니다.

## 프로젝트 파일 구성

```text
prompt-manager/
│
├── prompt_manager.py
├── prompts.json
├── README.md
└── .gitignore
```

### prompt_manager.py

프롬프트 등록, 검색, 조회, 즐겨찾기 등 프로그램의 주요 기능을 담당합니다.

### prompts.json

사용자가 등록한 프롬프트와 즐겨찾기 상태를 저장합니다.

### README.md

프로젝트의 목적, 실행 방법, 주요 기능 등을 설명합니다.

### .gitignore

Git에서 관리하지 않을 파일이나 폴더를 지정합니다.

## Git / GitHub 활용

Git을 이용하여 프로그램의 변경 이력을 기능 단위로 관리했습니다.

주요 작업 과정은 다음과 같습니다.

- 프로젝트 초기 구조 생성
- 프롬프트 상세 보기 및 즐겨찾기 기능 추가
- 프롬프트 목록 출력 개선
- 입력값 검증 기능 추가
- 카테고리별 조회 기능 추가
- 프롬프트 검색 기능 개선
- 메뉴 기능 함수화
- 프롬프트 추가 기능 함수화
- 카테고리 조회 기능 함수화
- feature 브랜치 생성 및 main 브랜치 병합
- 여러 줄 프롬프트 입력 기능 추가
- JSON 파일 저장 및 불러오기 기능 추가

기능별로 커밋을 생성하여 프로그램이 개선되는 과정을 Git 이력으로 확인할 수 있도록 관리했습니다.

## 추가 구현 기능

기본적인 프롬프트 관리 기능 외에 다음 기능을 추가로 구현했습니다.

### 여러 줄 프롬프트 입력

한 줄짜리 간단한 프롬프트뿐 아니라 실제 생성형 AI에서 사용하는 긴 프롬프트를 저장할 수 있도록 개선했습니다.

### JSON 파일 영구 저장

프로그램을 종료해도 등록한 프롬프트가 사라지지 않도록 `prompts.json`에 데이터를 저장하도록 구현했습니다.

### JSON 자동 불러오기

프로그램 실행 시 저장된 JSON 데이터를 자동으로 불러오도록 구현했습니다.

### 즐겨찾기 상태 저장

즐겨찾기 추가 및 해제 결과도 JSON 파일에 저장하여 프로그램을 다시 실행해도 상태가 유지되도록 했습니다.

## 프로젝트를 통해 학습한 내용

이 프로젝트를 통해 Python의 기본 문법뿐 아니라 실제 프로그램을 단계적으로 개선하는 과정을 학습했습니다.

- 리스트와 딕셔너리를 활용한 데이터 관리
- 함수 정의 및 호출
- 조건문과 반복문
- 사용자 입력 처리
- 입력값 검증
- 파일 읽기와 쓰기
- JSON 데이터 저장 및 불러오기
- Git commit을 이용한 변경 이력 관리
- Git branch 생성 및 병합
- GitHub 원격 저장소 push
- README를 이용한 프로젝트 문서화

단순히 코드를 작성하는 것뿐 아니라 기능을 추가하고, 실행 결과를 확인하고, Git으로 변경 이력을 관리하는 전체 개발 과정을 경험하는 것을 목표로 했습니다.
