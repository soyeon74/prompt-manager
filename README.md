# 나만의 프롬프트 관리 프로그램

Python으로 만든 콘솔 기반 프롬프트 관리 프로그램입니다.

프롬프트를 등록하고 카테고리별로 조회하거나 검색할 수 있으며,
자주 사용하는 프롬프트를 즐겨찾기로 관리할 수 있습니다.

## 개발 환경

- Python 3.10 이상
- VSCode
- Git / GitHub

## 실행 방법

1. 프로젝트 폴더를 엽니다.
2. 터미널에서 다음 명령어를 실행합니다.

python prompt_manager.py

3. 메뉴 번호를 입력하여 원하는 기능을 선택합니다.

## 주요 기능

1. 프롬프트 목록 보기
2. 새로운 프롬프트 추가
3. 카테고리별 프롬프트 조회
4. 제목 또는 내용으로 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 추가 및 해제
7. 즐겨찾기 목록 보기
8. 잘못된 메뉴 번호 입력 처리
9. 프로그램 종료

## 프롬프트 데이터

각 프롬프트는 다음 정보를 포함합니다.

- 제목
- 내용
- 카테고리
- 즐겨찾기 여부

프로그램 실행 중 추가한 프롬프트와 즐겨찾기 상태는 유지되며,
프로그램을 종료하면 초기화됩니다.

## 기본 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

프롬프트 추가 시 새로운 카테고리를 직접 입력할 수도 있습니다.

## 기본 등록 프롬프트

프로그램 실행 시 다음 3개의 샘플 프롬프트가 기본으로 등록되어 있습니다.

- 블로그 작성
- 제품 이미지 생성
- 광고 영상 만들기

## Git / GitHub

Git을 사용하여 기능 단위로 코드 변경 이력을 관리했습니다.

별도의 feature 브랜치에서 프롬프트 목록 기능을 작업한 후
main 브랜치로 병합하는 과정을 수행했습니다.
