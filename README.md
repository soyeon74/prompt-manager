# 나만의 프롬프트 관리 프로그램

Python으로 만든 콘솔 기반 프롬프트 관리 프로그램입니다.

자주 사용하는 프롬프트를 등록하고 카테고리별로 조회하거나 검색할 수 있으며,
즐겨찾기로 관리할 수 있습니다.

여러 줄로 작성된 긴 프롬프트도 등록할 수 있으며,
등록한 프롬프트는 JSON 파일에 저장되어 프로그램을 종료한 후 다시 실행해도 유지됩니다.

## 개발 환경

- Python 3.10 이상
- VSCode
- Git / GitHub

## 실행 방법

1. 프로젝트 폴더를 VSCode에서 엽니다.
2. 터미널에서 다음 명령어를 실행합니다.

```bash
python prompt_manager.py
